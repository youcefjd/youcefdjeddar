Agentic AI is changing how software gets built and shipped. I've been using these tools in production and want to write down what I'm learning.

Using AI to build a weekend project is nothing like running it in production. Everyone's seen the demos where you spin up a todo app in 5 minutes and mass produce vibe-coded prototypes that mass produce bugs. Now try shipping that to real users, maintaining it, and debugging it at 2am when something breaks. It's a very different job.

This isn't a beginner tutorial series and it isn't hype. It's notes from actually doing the work.

## What I'll cover

- **Agentic AI in practice** — autonomous systems that reason, plan, and execute real tasks
- **MCP servers** — building integrations with the Model Context Protocol
- **AI-assisted coding** — using Claude Code, Copilot, and similar tools as core parts of production workflows
- **What actually ships** — separating signal from noise

The posts will be practical and honest. When something doesn't work, I'll write about that too.
